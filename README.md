# Курс Go

Небольшой практический курс Go для фронтендера, который переходит к бэкенду.
Построен на реальном проекте (путь модуля в примерах обезличен как
`example.com/billboard`).

**Открыть:** https://stoyanovk.github.io/go-course/

## Структура
- `index.html` — главная, карта из 15 тем в 3 блоках.
- `lessons/` — уроки (`NNNN-*.html`).
- `reference/glossary.html` — глоссарий, источник истины по терминам.
- `assets/` — общие стили и виджет квиза.

## Порядок
Блок 1 (читать код) целиком → темы 8–10 + тулинг(14) параллельно →
конкурентность(11) в конце.

Сайт статический — GitHub Pages из ветки `main`, папка `/`.
