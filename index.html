Главная курса

Учим Go — от синтаксиса до production

Практический курс для фулстека, который уже пишет серверы на Node и Python, а теперь берёт Go. Цель — писать боевой HTTP-сервис на Go: идиоматично, с конкурентностью без багов, Postgres, Redis, тестами и вменяемой архитектурой.

3 рефлекса, которые надо переучить с TS Ошибки — это значения (нет try/catch, есть if err != nil) · значения копируются (указатель-или-значение — реальный выбор) · конкурентность настоящая (общие данные требуют синхронизации). Эти три идеи возвращаются в каждом блоке.

Практика прямо здесь: в ранних уроках — запускаемый Go в браузере (нажми «Запустить» — код исполнится). Где браузер не тянет по-настоящему (реальный сервер, база, redis) — короткие программы под go run у тебя на машине.

Блок A — язык

Чтобы читать и писать Go, не думая на TS.

  • 1 · Синтаксис Go — func, переменные, типы, управление, глазами JS/TS
  • 2 · Структуры, методы, указатели — struct, ресиверы, указатель vs значение (рефлекс #2)
  • 3 · Конкурентность — горутины, каналы, select, sync, context

Блок B — сервис

Собираем настоящий бэкенд (запуск локально).

  • 4 · HTTP — net/http, хендлеры, роутинг, middleware, JSON
  • 5 · PostgreSQL — pgx, пул, транзакции, миграции
  • 6 · Redis — go-redis, кэш, TTL, паттерны

Блок C — инженерия

  • 7 · Тестирование — table-driven, httptest, моки через интерфейсы
  • 8 · Архитектура — слои handler→service→repository, DI без магии
  • 9 · Production — конфиг, логи, сборка, Docker, healthcheck

Справочник: Программа курса · Глоссарий — источник истины по терминам.

Порядок линейный: Блок A → B → C. Но идиоматику и 3 рефлекса вплетаем везде.
