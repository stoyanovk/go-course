Синтаксис Go

Ты уже пишешь серверы на Node и Python. Здесь — тот же самый мозг, но другой синтаксис. Разберём форму программы, переменные, управление и «фишку» Go — множественный возврат. Код запускается прямо на странице.

Что ты сможешь после урока Прочитать и написать маленькую программу на Go — пакет, func, переменные, if/for/switch — и функцию, которая возвращает значение и ошибку. Это фундамент любого хендлера.

💡 В блоках с тёмным фоном жми ▶ Запустить — Go выполнится в браузере. Первый запуск качает песочницу (~8 МБ, один раз), потом мгновенно. Код можно менять прямо в поле.

1. Форма программы

Каждая программа на Go живёт в пакете. Точка входа — функция main в пакете main. Импорты — явные, по одному на нужный пакет.

Если пришёл из JS/TS Нет console.log — есть fmt.Println. Нет отдельного файла-точки входа по имени — точка входа это функция main. Точки с запятой ставит компилятор сам, руками их не пишут.

2. Переменные, типы, zero value

Два способа объявить переменную:

  • x := 5 — короткое объявление с выводом типа. Только внутри функций.
  • var x int — полная форма. Тип пишется после имени.

Главное отличие от JS: в Go нет undefined. Необъявленного «пусто» не существует — у каждого типа есть zero value: 0, "", false, nil.

Ловушка для JS-разработчика Go не приводит типы неявно. int и float64 нельзя складывать без явного преобразования, а "3" + 4 — ошибка компиляции, не "34". Строгость сильнее, чем в TS.

3. Управление: if / for / switch

Скобок вокруг условия нет, фигурные скобки обязательны. И запомни: в Go только один цикл — for. Он же заменяет while.

Три отличия от JS for count < 3 { } — это и есть while. · switch не проваливается: break писать не надо. · Условие без скобок: if x > 0 {, а не if (x > 0).

4. Множественный возврат → рефлекс «ошибки-значения»

Функция может вернуть несколько значений. Идиома Go: последнее — это error. Ошибку не «бросают» — её возвращают, а вызывающий сразу проверяет if err != nil. Это первый из трёх рефлексов курса.

Зачем это на бэкенде Каждый твой хендлер будет так выглядеть: распарсил ввод → if err != nil → вернул 400. Прочитал из базы → if err != nil → вернул 500. Привыкай к if err != nil — это половина Go-кода. _ — это «мне не нужно это значение».
