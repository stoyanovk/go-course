Глоссарий

Источник истины по терминам курса. Все уроки используют эти слова одинаково. Пополняется по ходу.

ТерминЗначение (коротко)Аналогия из TS/JS
пакет (package) Одна папка = один пакет. Все файлы .go в папке имеют одну строку package X и видят имена друг друга без импорта. Как модуль, но граница — папка, а не файл.
модуль (module) Весь проект: имя + зависимости, объявлены в go.mod. Импорты идут по пути модуля. Как репозиторий со своим package.json.
публичное (exported) Имя с Заглавной буквы. Видно из других пакетов. Неявный export.
приватное (unexported) Имя с маленькой буквы. Видно только внутри своего пакета. Приватное для модуля (без export).
структура (struct) Тип, объединяющий именованные поля. Главная форма данных в Go. Как тип-объект (interface) + сам объект.
ресивер метода (b Banner) или (b *Banner) перед именем метода. По значению = работает с копией; по указателю = может менять оригинал. this, но копия-или-ссылка выбирается явно.
указатель (pointer) *T = «адрес значения T». Даёт делить/менять одно значение или сказать «не задано» через nil. Прямой аналогии нет; ближайшее — «передача по ссылке».
zero value У каждого типа есть значение по умолчанию: 0, "", false, nil. «undefined» не существует. Заменяет undefined / неинициализированное.
слайс (slice) Растущее «окно» над массивом: есть длина + вместимость. []T. Как Array<T>, но с механикой capacity.
мапа (map) map[K]V. map[string]struct{} используют как Set (множество). Map / Record; приём со struct{} = Set.
интерфейс (interface) Список сигнатур методов. Тип удовлетворяет ему просто потому, что имеет эти методы — без слова implements. Структурная типизация (как интерфейсы TS), но для методов.
ошибка (error) Встроенный интерфейс. Ошибки возвращаются как значения, проверяются через if err != nil. Нет throw/catch. Противоположность try/catch.
defer «Выполни это, когда функция завершится.» Для очистки (rows.Close()). Как finally, но привязывается в месте вызова.
Пополняется по ходу Новые термины попадают сюда сразу, как только урок их вводит — чтобы это было единственное место, где стоит искать слова.
