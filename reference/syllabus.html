Программа курса

9 этапов от синтаксиса до production. Каждый этап — короткие уроки с практикой. Порядок линейный, но 3 рефлекса «переучить с TS» вплетаем везде.

Стержень курса — 3 рефлекса Ошибки — значения · значения копируются (указатель vs значение) · конкурентность настоящая. Возвращаются в каждом блоке.

Блок A — язык

1 · Синтаксис Go

Пакет и main, func, переменные (:=, var), базовые типы, if/for/switch, множественный возврат. Сравнение с JS/TS.

Источник: A Tour of Go · Go by Example

2 · Идиоматичный Go

Ошибки как значения (if err != nil, оборачивание), указатель vs значение, структуры и методы-ресиверы, маленькие интерфейсы, zero value, именование.

Источник: Effective Go · 100 Go Mistakes

3 · Конкурентность

Горутины, каналы (буфер/close/range), select, sync.Mutex/ WaitGroup, context, паттерны (pipeline, fan-out). Гонки и -race.

Источник: Go blog: pipelines · context · книга «Concurrency in Go»

Блок B — сервис

4 · HTTP

net/http: хендлеры, ServeMux (роутинг 1.22+ с методами), middleware, чтение/запись JSON, статусы, graceful shutdown.

Источник: «Let's Go» (Alex Edwards) · routing 1.22

5 · PostgreSQL

pgx: подключение и пул, запросы, сканирование, транзакции с context, миграции. Repository-слой поверх базы.

Источник: pgx · «Let's Go»

6 · Redis

go-redis: клиент, GET/SET c TTL, кэш поверх Postgres, инвалидация, простые паттерны (rate limit, lock).

Источник: go-redis docs

Блок C — инженерия

7 · Тестирование

testing, table-driven тесты, t.Run, httptest, подмена зависимостей через интерфейсы, go test -race -cover.

Источник: Learn Go with Tests

8 · Архитектура

Слои handler → service → repository, зависимость от интерфейсов, dependency injection без фреймворка, структура каталогов, internal/.

Источник: «Let's Go Further» · project layout

9 · Production

Конфиг (env/флаги), структурное логирование (log/slog), сборка (go build, флаги), Docker (multi-stage), healthcheck, наблюдаемость.

Источник: log/slog · go vet · golangci-lint

Полный список источников и сообществ — в рабочем файле RESOURCES.md (локально). Вопросы по любому уроку задавай учителю в чате.
